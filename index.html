GET STARTED

安装和使用。

CMake + Ninja + vcpkg。先准备工具链，再获取带 LFS 素材的完整源码。

CMake ≥ 3.25C++17 编译器NinjaGit LFSvcpkgSlang ≥ 2026.18.1
01

准备平台工具

macOS / Apple Silicon

安装 Xcode Command Line Tools，以及 CMake、Ninja、Git LFS。原生 Metal 后端需要 macOS 13+；Slang 预编译包可能要求更高版本。

xcode-select --install
brew install cmake ninja git-lfs

Windows

安装 Visual Studio 2022 的“使用 C++ 的桌面开发”、Windows SDK、CMake、Ninja 和 Git LFS。在 x64 Native Tools 命令行中构建。Vulkan 后端另需 Vulkan SDK。

Linux

准备 GCC 或 Clang、CMake、Ninja、Git LFS 和 Vulkan SDK。按发行版安装 GLFW 所需的 X11 / Wayland 开发依赖；确保显卡驱动支持 Vulkan。

依赖由 vcpkg 清单管理。先安装并 bootstrap vcpkg；Slang 默认通过清单特性提供。

02

获取源码和素材

git lfs install
git clone --recurse-submodules https://github.com/LazyJazzDev/LongMarch.git
cd LongMarch
git -C assets lfs pull

已有工作副本：执行 git submodule update --init --recursive 和 git -C assets lfs pull。素材使用仓库固定的子模块版本，不使用 --remote 更新。

03

配置 Release 构建

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DVCPKG_PATH=/path/to/vcpkg -DLONGMARCH_DISABLE_PYTHON=ON -DLONGMARCH_ENABLE_METAL=ON -DLONGMARCH_DISABLE_VULKAN=ON

将 vcpkg 路径替换为本机路径。示例关闭可选 Python 绑定；CUDA 由工具链检测，可用 -DLONGMARCH_DISABLE_CUDA=ON 关闭。更换生成器或工具链时使用新的构建目录。

04

编译并运行第一个样例

cmake --build build --target demo_graphics_hello
./build/demo/graphics_hello/demo_graphics_hello --module triangle

Windows 下运行对应的 .exe。Ninja 默认构建不包含样例与测试，需显式指定目标。用 --list 查看 Graphics Hello 的模块。

交互游戏

2048

保留经典棋盘、配色、菜单与动画，用方向键移动。共享 GUI surface 负责底层渲染与事件。连续点击 SCORE 五次启动 AI，再点一次停止。

cmake --build build --target demo_2048
./build/demo/2048/demo_2048

cmake --build build --target demo_gol

图形基础

Graphics Hello

三角形、混合、立方体、纹理、窗口缩放、HDR 与光线追踪模块。RT 模块是否可运行取决于后端能力。

cmake --build build --target demo_graphics_hello
./build/demo/graphics_hello/demo_graphics_hello --list
GPU 计算

NBody

用计算着色器模拟多体粒子运动。交互模式包含参数面板；独立的 CUDA 版本需要 CUDA 工具链和对应硬件。

cmake --build build --target demo_nbody_cs
./build/demo/nbody_cs/demo_nbody_cs --mode interactive
渲染工具

Sparkium GUI

浏览素材场景、选择渲染路径并调整画面参数。可传入 JSON 场景或目录；默认读取 assets/scenes。

cmake --build build --target demo_sparkium_gui
./build/demo/sparkium_gui/demo_sparkium_gui
相机模型

Thin Lens

交互调整焦距、光圈与焦平面，观察不同深度物体的景深变化。自动选择可用的追踪路径。

cmake --build build --target demo_thin_lens
./build/demo/thin_lens/demo_thin_lens
界面与自定义绘制

GUI Showcase

屏幕空间面板、粒子 Canvas 与带深度测试的世界空间面板，展示同一 GUI 框架的 2D / 3D 混合使用。

cmake --build build --target demo_gui
./build/demo/gui/demo_gui
离线渲染

Sparkium CLI

从 JSON 场景渲染输出图片，适合脚本、对比实验和无窗口运行。下面使用 Metal 软件回退管线。

cmake --build build --target demo_sparkium_cli
./build/demo/sparkium_cli/demo_sparkium_cli assets/scenes/cornell_box/scene.json --backend metal --pipeline rt_fallback -o cornell.png
从仓库根目录运行上述命令；Windows 使用对应的 .exe。网页版为单独发布的 Web 构建，功能与原生样例可能不同。更多样例见 demo 目录。

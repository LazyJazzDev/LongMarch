# LongMarch agent instructions

Before working in this repository, read and follow
[longmarch-project-principles](.agents/skills/longmarch-project-principles/SKILL.md).
It records the user's project conventions for commit messages, squash merges,
PR history, and asset references. These instructions apply to every agent
working in this repository, including delegated agents.

Use the repository copy even if your runtime does not automatically discover
skills. Explicit current user instructions take precedence. Keep the versioned
skill and any locally installed copy in sync when updating these conventions.

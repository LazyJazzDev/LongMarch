职责与设计

GPU 软件 BVH 和原生 Ray Query 共用的计算路径追踪程序。；本文件定义类型与调用接口。

  • 软件树叶数向上补到 2 的幂，每树最多 2^21 个实际叶；节点 32 字节，实例记录 112 字节，实例表头 16 字节，构建参数 256 字节。
  • 软件 BLAS 仅在树布局/几何指针/三角数变化时重建；TLAS 每帧重建。构建次序为叶初始化、归约边界、Morton key、Bitonic sort、叶重排、再归约。
  • Ray Query 使用硬件 BLAS/TLAS，不执行软件树构建；计算 renderer 仍使用相同材质分派与数据注册。
  • 材质源码去掉 include/pragma，按 shader_graph 标记与完整文本去重，分别放命名空间；图材质分离 GraphSurface 求值与共享 BSDF。编译键还包括相机文件/入口和各资源数量。
  • 矩阵行列式绝对值小于 1e-20 拒绝；实例/节点字节地址越过 uint32 范围拒绝。AddInstance 只保存，Update 才执行校验和构建。

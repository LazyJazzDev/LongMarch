职责与设计

配置六闭包、混合求值和按权重采样。

  • 背面用局部interface_ior=1/ior，不改变原材质ior，因此重复Eval/Sample不会来回翻转IOR。
  • 漫反射权重=(1-metallic)*(1-transmission)*(1-subsurface)；本文件不自行实现次表面传播，图材质在外层处理随机游走。
  • anisotropic_rotation以整圈为单位乘2π；clearcoat固定IOR1.5，alpha=clearcoat_roughness²。
  • SamplePrincipledBSDF归一化CDF前未检查total_cdf=0；无有效闭包时CDF可为NaN，外围应以零pdf终止。

对象与接口

同名重载分别列出；私有成员用于解释实现边界，不构成对外接口。

261   float transmission_weight = microfacet_bsdf_refract_closure.sample_weight;

273   // while evaluating only the continuous reflection at this direction.

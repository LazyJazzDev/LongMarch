职责与设计

Core设置、设备初始化、资源工厂、提交与CUDA屏障绑定。

  • CoreSettings可改frames_in_flight/enable_debug，但构造Core后修改该设置对象不自动更新Core。
  • 资源工厂用keep_alive<0,1>让返回对象保留Core；compute program额外保留shader，RT三shader重载保留三者。
  • create_shader把字符串写入临时VFS main.slang；create_shader_from_directory加载目录解决include。load_image_from_file与create_cuda_buffer检查错误码并抛异常，许多其他工厂未检查。
  • create_tlas的(pair)重载接受4×4行主序列表，create_blas的BufferRange重载未额外保留range对象；调用方需维持依赖资源。

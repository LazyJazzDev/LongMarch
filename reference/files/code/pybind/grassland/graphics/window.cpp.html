职责与设计

Window尺寸/焦点/HDR、输入事件、手势和兼容ImGui帧接口绑定。

  • get_size/get_framebuffer_size分别逻辑窗口尺寸与像素尺寸，GLM向量转tuple；frame_size/work_area为四元素tuple。
  • register_*返回回调ID，各unregister_*用相同ID移除；窗口保存Python callable，回调闭包反向持窗可能形成引用环。
  • drop回调只传路径列表；magnify传scale,x,y,phase；display_brightness传包含五项亮度信息的dict。
  • poll_events是静态方法；本绑定未主动释放GIL来运行GPU等待或额外获取GIL执行C++线程事件。

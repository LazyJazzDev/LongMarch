职责与设计

命令录制桥接，含资源重载与Python列表/标量到原生结构的转换。

  • cmd_bind_resources的keep_alive<1,2>保留的是slot整数，cmd_bind_vertex_buffers保留的是first_binding；不保证实际列表资源存活。
  • cmd_begin_rendering无目标保活；cmd_present只保留window，未保留image。所有引用资源需外部保留至提交完成。
  • cmd_draw虽然参数名index_count、docstring写indexed，实际调用非索引CmdDraw。cmd_dispatch宽高为工作组数；cmd_dispatch_rays为射线维度。
  • cmd_clear_image可传四float颜色（校验长度）或单float深度；viewport/scissor用独立坐标参数组装。

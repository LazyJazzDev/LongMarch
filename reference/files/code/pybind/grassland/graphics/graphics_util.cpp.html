职责与设计

导出RHI枚举、位标志运算与可修改参数结构。

  • BackendAPI含Metal/Vulkan/D3D12；默认API为模块常量，SHADER_TYPE_FRAGMENT别名PIXEL。enum export_values使枚举值也出现在模块级。
  • SamplerInfo四种构造重载，BlendState默认/enable/六项混合重载；字段直接def_readwrite，无状态校验。
  • BufferRange构造保留原Buffer，但公开buffer setter未建立新的保活关系。RayTracingInstance.acceleration_structure setter只存裸指针，调用方须保留对象。
  • RayTracingInstance.transform是3×4行主序；ID和hit_group_offset为24bit、mask/flags为8bit，setter无显式范围检查，赋入位域可能截断。
  • 两类RT flags提供|/&/^/~和bool；__str__若未知值使用0x前缀加十进制to_string，不能视作可靠十六进制序列化。

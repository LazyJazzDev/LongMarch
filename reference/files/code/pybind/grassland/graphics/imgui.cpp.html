职责与设计

保留的Python ImGui即时控件子集。

  • 在window.begin_imgui_frame与end_imgui_frame之间使用；begin即使返回False也要end。text使用TextUnformatted，文本不当格式串。
  • checkbox/slider返回(changed,value)，不会修改Python不可变参数本身；slider格式字符串直接传ImGui，需要匹配数值类型。
  • set_ini_filename使用全局静态string储存，多个context切换文件名会共享这一个储存位置；None禁用保存。

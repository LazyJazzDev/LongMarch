math_static_collision.h

code/grassland/math/math_static_collision.h · 122 行 · 查看版本源码 ↗

职责与设计

静态距离、线段相交和射线命中；本文件定义类型与调用接口。

  • 实现显式实例化 float 和 double。带输出参数重载返回最近点参数，不带参数重载仅保留距离。
  • 零长度边和退化面没有统一处理；近平行直线退回点线距离，近平行射线/三角形返回未命中。

直接依赖

  • grassland/math/math_aabb.h
  • grassland/math/math_util.h

同名重载分别列出；私有成员用于解释实现边界，不构成对外接口。

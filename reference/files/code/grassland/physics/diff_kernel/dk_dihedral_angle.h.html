职责与设计

二面角、弯曲能量及局部导数；本文件定义类型与调用接口。

  • V 的四列是 v0/v1/v2/v3，共享边为 v1→v2；角度为弧度。
  • 组合式与直接式并存；DihedralEnergy=(angle−rest_angle)²，差值不作周期折返。
  • 保留的大段注释实现不参与编译；活动宏用于 Hessian 分块和局部快速路径。

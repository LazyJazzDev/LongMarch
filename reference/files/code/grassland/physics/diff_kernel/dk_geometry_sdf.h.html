职责与设计

七种解析距离核与导数；本文件定义类型与调用接口。

  • 点、线、线段返回无符号距离；球、胶囊、立方体、平面带符号。
  • CubeSDF.size 是半边长；PlaneSDF.normal 和 LineSDF.direction 要求单位向量才能具有距离语义。
  • ValidInput 并非都检查奇点；线核始终 true，但查询点在线上时导数有除零。

直接依赖

  • grassland/physics/diff_kernel/dk_basics.h

graphics_util.h

code/grassland/graphics/graphics_util.h · 311 行 · 查看版本源码 ↗

职责与设计

跨后端枚举、POD 描述符与颜色/格式工具；本文件定义类型与调用接口。

  • 包含图像格式、缓冲类型、着色器资源、顶点输入、混合与 RT 实例描述。
  • BackendAPI 默认值按编译宏优先 Metal、再 D3D12、否则 Vulkan；SupportBackendAPI 仅判断编译支持。
  • ClearValue 是无标签 union，必须与目标图像颜色/深度格式匹配。
扩展语法核对记录

BACKEND_API_DEFAULT的枚举初始化由条件编译选择Metal/Vulkan/D3D12；已核对BackendAPI原始枚举与对应架构说明，条件分支保留在完整源码。

直接依赖

  • GLFW/glfw3.h
  • glm/glm.hpp
  • grassland/util/util.h

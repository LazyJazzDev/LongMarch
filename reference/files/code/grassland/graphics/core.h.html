职责与设计

图形设备工厂、后端选择与公共创建助手；本文件定义类型与调用接口。

  • Core 保存 frames_in_flight/debug 设置，构造尝试 GLFW 初始化但不因无窗口环境立即拒绝离屏运行。
  • 自动选设备根据 score 排序，可要求完整 RT 支持；ray query 不通过这一布尔选项筛选。
  • 无符合设备时仍把 -1 交给具体后端处理；调用方检查初始化结果。

直接依赖

  • grassland/graphics/graphics_util.h
  • cuda_runtime.h

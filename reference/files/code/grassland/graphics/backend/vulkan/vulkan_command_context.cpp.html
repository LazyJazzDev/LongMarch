vulkan_command_context.cpp

code/grassland/graphics/backend/vulkan/vulkan_command_context.cpp · 271 行 · 查看版本源码 ↗

职责与设计

命令对象录制、descriptor容量预算及图像状态缓存。；本文件实现接口行为。

  • 在rendering期间绑定的图形资源图像登记到BeginRendering对象，屏障在开始rendering前集中执行。
  • RequireImageState首次假定GENERAL/TOP_OF_PIPE/无access，每次调用都发barrier；提交末尾恢复GENERAL并清状态。
  • CmdCopyBuffer不登记动态buffer上传，也不额外插buffer barrier；调用方安排依赖与资源状态。
  • CmdTimestamp借用query pool，调用方保持到GPU完成。

215 void VulkanCommandContext::CmdPresent(Window *window, Image *image) {
216   auto native_window = dynamic_cast<VulkanWindow *>(window);
217   auto native_image = dynamic_cast<VulkanImage *>(image);
218   auto extent = native_window->SwapChainExtent();
219   auto composition = dynamic_cast<VulkanImage *>(window->PrepareHDRComposition(core_, {extent.width, extent.height}));
220   if (composition) {
221     commands_.push_back(std::make_unique<VulkanCmdPresent>(native_window, native_image, composition));
222     auto aligned = dynamic_cast<VulkanImage *>(window->AlignHDRComposition(this));
223     commands_.push_back(std::make_unique<VulkanCmdPresent>(native_window, aligned, nullptr, false));
224   } else {
225     commands_.push_back(std::make_unique<VulkanCmdPresent>(native_window, native_image));
226   }
227   windows_.insert(native_window);
228 }

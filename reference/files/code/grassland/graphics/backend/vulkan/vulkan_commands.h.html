vulkan_commands.h

code/grassland/graphics/backend/vulkan/vulkan_commands.h · 277 行 · 查看版本源码 ↗

职责与设计

逐命令把值参数、借用资源和Program布局翻译成Vulkan调用。；本文件定义类型与调用接口。

  • descriptor写入数量取Program声明，但info数组按传入数量建立；不足会使原生调用读取数组外内存，必须精确匹配。
  • render area取所有附件的最小尺寸，无附件时用设备maxFramebuffer尺寸；LOAD/STORE，不自动清除。
  • viewport通过y+height和负height翻转Y；索引固定uint32。
  • Dispatch/TraceRays末尾ALL_COMMANDS写→读barrier；CopyBuffer没有额外屏障。

  • grassland/graphics/backend/vulkan/vulkan_core.h

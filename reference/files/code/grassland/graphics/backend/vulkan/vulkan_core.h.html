职责与设计

统一资源工厂、设备选择、提交/呈现/完成回调与CUDA同步。；本文件定义类型与调用接口。

  • 静态图像创建后同步转GENERAL；Slang使用spirv_1_5及dx-layout。
  • descriptor pool按每类与set数倍增，帧槽复用时reset；提交先上传动态Buffer，再加ALL_COMMANDS内存barrier。
  • 等待窗口image semaphore的stage设为COLOR_ATTACHMENT_OUTPUT，但Present路径首先transfer clear/blit；这不是完整验证过的transfer等待协议。
  • Submit末尾等待transfer_queue idle，而它实际是同一graphics queue，因此当前提交也被等待完成。
  • WaitGPU只等graphics queue并执行回调，未检查idle返回码；析构device idle但不执行剩余post callbacks。

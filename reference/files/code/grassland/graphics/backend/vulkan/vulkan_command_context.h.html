vulkan_command_context.h

code/grassland/graphics/backend/vulkan/vulkan_command_context.h · 100 行 · 查看版本源码 ↗

职责与设计

命令对象录制、descriptor容量预算及图像状态缓存。；本文件定义类型与调用接口。

  • 在rendering期间绑定的图形资源图像登记到BeginRendering对象，屏障在开始rendering前集中执行。
  • RequireImageState首次假定GENERAL/TOP_OF_PIPE/无access，每次调用都发barrier；提交末尾恢复GENERAL并清状态。
  • CmdCopyBuffer不登记动态buffer上传，也不额外插buffer barrier；调用方安排依赖与资源状态。
  • CmdTimestamp借用query pool，调用方保持到GPU完成。

code/grassland/graphics/backend/vulkan/vulkan_window.h · 104 行 · 查看版本源码 ↗

职责与设计

surface、swapchain、HDR切换、semaphore和兼容ImGui。；本文件定义类型与调用接口。

  • HDR只接受RGBA16F/scRGB线性或两种10bit/PQ组合，不静默回退SDR，并要求目标格式BLIT_DST。
  • Rebuild尝试用oldSwapchain创建，失败后重建旧模式；恢复再失败则标记presentation_failed，禁止后续Acquire/Present。
  • semaphore数组按初始交换链image数分配，但按Core CurrentFrame索引；FramesInFlight须不超过数组长度，重建不调整semaphore数组。
  • Acquire把SUBOPTIMAL/OUT_OF_DATE直接视为异常；Present才对这两种结果Rebuild。
  • HDRFramebuffer只首次创建，必须与当前合成图像保持一致；Rebuild清缓存。

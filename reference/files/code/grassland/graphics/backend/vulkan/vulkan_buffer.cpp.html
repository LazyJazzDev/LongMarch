vulkan_buffer.cpp

code/grassland/graphics/backend/vulkan/vulkan_buffer.cpp · 322 行 · 查看版本源码 ↗

职责与设计

VMA静态/逐帧动态Buffer及CUDA外部内存实现。；本文件实现接口行为。

  • Size保存请求字节数；Static/CUDA传输WaitGPU，Dynamic仅Map CPU staging，下载不反映GPU写入。
  • Dynamic DeviceAddress返回staging地址供即时AS构建，Buffer返回当前帧GPU副本；TransferData整缓冲上传并按需重建。
  • Map返回码和范围没有全面检查，未显式flush/invalidate非coherent内存；调用方不能假设所有memory type都被正确处理。
  • CUDA Buffer无论RT能力都会调用KHR address函数；需确保device address已启用且函数已加载。Reset未清cuda_memory_，重复Reset存在重复destroy风险。

180 void VulkanDynamicBuffer::TransferData(VkCommandBuffer cmd_buffer) {
181   size_t frame = core_->CurrentFrame();
182   if (buffer_sizes_[frame] != size_) {
183     vmaDestroyBuffer(core_->Allocator(), buffers_[frame], allocations_[frame]);
184     vulkan::ThrowIfFailed(core_->CreateBuffer(size_, StaticUsage(core_), VMA_MEMORY_USAGE_GPU_ONLY, &buffers_[frame],
185                                               &allocations_[frame]),
186                           "Failed to resize Vulkan dynamic device buffer");
187     buffer_sizes_[frame] = size_;
188   }
189   VkBufferCopy copy_region{};
190   copy_region.size = size_;
191   vkCmdCopyBuffer(cmd_buffer, staging_buffer_, buffers_[frame], 1, &copy_region);

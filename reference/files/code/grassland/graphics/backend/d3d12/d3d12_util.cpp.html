职责与设计

原生资源工厂、适配器枚举和抽象枚举转换。；本文件实现接口行为。

  • Buffer 按256字节对齐；默认 heap Buffer 允许 UAV。Image 为单mip单sample Tex2D，深度使用DEPTH_STENCIL，其余RENDER_TARGET|UAV，初始GENERIC_READ。
  • SwapChain采用FLIP_DISCARD；RGBA16F时尝试线性P709色彩空间，系统不支持时不会因该检查失败而拒绝创建。
  • 枚举跳过软件适配器，评分为专用显存MiB加光追支持100000。

d3d12_command_context.h

code/grassland/graphics/backend/d3d12/d3d12_command_context.h · 102 行 · 查看版本源码 ↗

职责与设计

延迟命令队列、描述符预算和局部资源状态跟踪。；本文件定义类型与调用接口。

  • CmdBindResources需先绑定对应Program，否则日志并返回；slot/count/跨后端指针多数未检查。
  • RequireResourceState假定首次出现的普通资源为GENERIC_READ；同状态不发屏障。提交末尾恢复原生状态，但context缓存未重置，按一次性context使用。
  • CBV大小按256对齐且offset须满足原生对齐；raw SRV/UAV按4字节计元素，非整倍数会截断。
  • CmdCopyBuffer头文件形参名写src/dst，而实现与基类实际约定是dst在前、src在后；调用时以实现语义为准。

d3d12_buffer.cpp

code/grassland/graphics/backend/d3d12/d3d12_buffer.cpp · 226 行 · 查看版本源码 ↗

职责与设计

静态、逐帧动态与CUDA共享缓冲实现。；本文件实现接口行为。

  • Size返回按256对齐的原生宽度，可能大于请求长度。上传/下载没有host长度或offset范围检查。
  • Static传输WaitGPU并使用Core缓存staging；Dynamic只Map CPU staging，Download不读取GPU执行结果；TransferData提交时复制整个staging。
  • Dynamic Resize只替换CPU staging，当前帧GPU资源在TransferData按需重建。
  • CUDA Download调用CopyNativeBuffer时沿用GENERIC_READ默认状态，而READBACK staging实际为COPY_DEST；这条路径存在状态假设不一致，不能视作已验证。

职责与设计

网格实例、环境光与方向光实体；本文件实现接口行为。

  • MeshObject 上传材质 albedo 与模型矩阵；GS 生成平面法线，传入顶点法线最终会被覆盖。
  • 环境光与方向光只在 lighting stage 绘制；程序采用 ONE+ONE 加法混合。

gui.h

code/snowberg/gui/gui.h · 147 行 · 查看版本源码 ↗

职责与设计

声明式控件收集、指针状态机和玻璃绘制；本文件定义类型与调用接口。

  • 输入在 BeginFrame 读取，Activate 在按下时捕获 ID、同控件内释放时触发点击；捕获只保留字符串。
  • 面板宽度由调用者指定，高度根据子控件累计；普通边距 18、纵向间隔 7、行间横向间距 8。
  • 圆角网格按物理宽/高/半径缓存；无淘汰策略，动态尺寸可能持续增大缓存。
  • EndFrame 借用返回的 scene 或自身 output_，应用负责提交命令及资源存活；尺寸/格式改变会 WaitGPU 后重建。

# GitHub Pages

Static pages published at https://lazyjazzdev.github.io/LongMarch/. The
`gh-pages` branch serves a copy of this directory at its root; after changing a
page here, copy the directory to that branch and push it.

- `gameoflife/privacy/`: privacy policy of the Game of Life app, linked from
  AppGallery Connect and App Store Connect.

`play/` on `gh-pages` is not copied from here: it is the web build of
`platforms/web` (`index.html`, `longmarch.js`, `longmarch.wasm`,
`longmarch.data`), published at https://lazyjazzdev.github.io/LongMarch/play/.
